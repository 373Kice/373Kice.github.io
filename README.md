# 373Kice · AI 投资决策报告平台

> AI 多智能体辩论式结构化投资决策报告 —— A股、板块、全球市场全覆盖

## 这是什么

373Kice 是一个基于 AI 多智能体协同系统生成的金融分析内容平台。每周发布：

- **A股大盘分析报告** — 四维分析（技术面/基本面/舆情/情绪）+ 多空辩论 + 综合风险评分
- **板块深度报告** — 稀土、半导体等重点赛道
- **全球市场周报** — 跨市场联动与宏观研判

每份报告包含：**明确的 BUY/SELL/HOLD 决策 + 置信度 + 风险评分 + 可执行操作计划**。

## 为什么是 AI 辩论

传统金融内容要么是数据罗列（无结论），要么是单人主观判断（有偏见）。

我们的方法：让 12 个专业 AI 分析师（技术派、基本面派、宏观派、情绪派、保守派、激进派…）对同一组数据独立分析、互相辩论，最终产出**带置信度的共识决策**。

这是**透明、可追溯、无利益冲突**的投资分析。
